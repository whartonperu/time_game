# PokéChase Japan 🚄⏰

A mobile-first game that teaches kids to tell the time on analogue and digital clocks.

**Play it here:** https://whartonperu.github.io/time_game/

## The story

A wild Pokémon has boarded a Shinkansen bullet train leaving Tokyo. You have a Time Machine that can warp you to the next station at the exact moment the train arrives, but only if you read the station clock correctly.

## How to play

1. Pick a Pokémon to chase and a clock style: **Analogue**, **Digital** or **Mixed**.
2. Read the arrival clock. The hour hand (orange) glows first: pick the **hour** from three choices.
3. The minute hand (blue) glows next: pick the **minutes** from three choices.
4. Get both right and you warp to the platform. Tap the Poké Ball to throw it.
5. If the Pokémon breaks free, it rides on to the next station and the chase continues.
6. Every Pokémon you catch is added to your Pokédex on the main screen.

The faster you read the clock, the better your chance of a catch.

## Features

- Five real Shinkansen lines (Tokaido, Tohoku, Hokuriku, Joetsu and Sanyo)
- Analogue clock with minute markers (0, 15, 30, 45) outside the face
- Wrong answers get a retry with fresh choices
- Works on phones, tablets and computers, with no install or sign-in
- A single self-contained HTML file

## Running it locally

Download `index.html` and open it in any web browser.
